# Behovsmatchning

En digital plattform där organisationer kan synliggöra sina behov, upptäcka liknande behov hos andra och matchas för potentiella samarbeten.

## ✨ Vad är det här?

Det här projektet är en behovsmatchningsplattform som hjälper organisationer att:

- Skapa och publicera behov
- Utforska andras behov
- Matchas med organisationer som har liknande eller kompletterande behov

Syftet är att främja samarbete, kunskapsutbyte och effektivare resursanvändning mellan organisationer i olika sektorer.

## 🔧 Funktionalitet

- Skapa behov med titel, beskrivning och kategori
- Visa andras behov i en överskådlig lista
- Se potentiella matchningar baserat på behovens likhet
- Matchningsstatus visas i gränssnittet

## ⚙️ Teknisk översikt

- **Frontend**: React + TypeScript
- **Stilmall**: Tailwind CSS
- **Backend**: AWS (Lambda, API Gateway, DynamoDB m.m.)
